# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately to **info@rexiumtech.com** with the subject line `[security] global-time-atlas`.

Include:

- A description of the issue and its impact
- Steps or a proof of concept to reproduce it
- The browser and OS versions involved

You will receive an acknowledgment within 7 days. Please do not open public GitHub issues for security concerns.

## Scope notes

Global Time Atlas is a fully client-side application with no server API, no accounts, and no data collection. Reports concerning the application code in this repository are in scope; reports concerning third-party services (for example, the static host or Google Fonts) should go to those providers.
